# PhizikaRK — формулы по физике

Веб-тренажёр: справочник из 102 формул, эквивалентные преобразования, постоянные и тест A–D со случайным порядком ответов.

## Открыть на телефоне

После включения GitHub Pages сайт будет здесь:

**https://zhanseitt.github.io/PhizikaRK/**

В браузере: «На экран „Домой“» / «Добавить на главный экран».

## Локально

Откройте `index.html` в браузере.
