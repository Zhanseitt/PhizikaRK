# Промпт: вставь в другой чат вместе с фото / текстом таблиц

Скопируй блок ниже целиком и отправь в чат. К сообщению приложи скрины или текст оставшихся формул.

---

Ты помогаешь заполнить файл `formulas.js` для сайта-тренажёра по физике.

## Задача
По моим скринам / тексту таблицы формул выпиши **все** формулы в виде готового JavaScript-массива объектов. В ответе дай **только** массив (или полный `const FORMULAS = [ ... ];`), без пояснений.

## Формат одного объекта
```js
{
  id: 15,                          // номер из таблицы №
  section: "1. Кинематика",        // заголовок раздела как в таблице
  name: "Путь при равномерном движении",
  formula: "s = vt",               // LaTeX БЕЗ внешних $...$
  notation: "s — путь, v — скорость, t — время",
  // в notation: символы можно в LaTeX (\\vec{v}, \\Delta t), пояснения — обычным русским текстом;
  // фрагменты разделяй «; » ; между символами и пояснением используй « — »
  boxed: false                     // true, если формула в рамке на скрине
}
```

## Правила LaTeX
- Дроби: `\\dfrac{a}{b}`
- Векторы: `\\vec{v}`, `\\Delta\\vec{r}`
- Индексы: `v_{\\mathrm{ср}}`, `a_{\\tau}`, `a_n`
- Корни: `\\sqrt{a_{\\tau}^2 + a_n^2}`
- Греческие: `\\omega`, `\\alpha`, `\\phi`
- Не экранируй кавычки внутри строк лишний раз; обратные слэши в JS-строке удваивай: `\\frac`

## Нумерация и разделы
- Сохраняй `id` как номер № из таблицы (1…102).
- `section` пиши точно как заголовок раздела («1. Кинематика», «2. Динамика», …).
- Если на скрине формула в чёрной рамке — `boxed: true`.
